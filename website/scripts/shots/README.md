# Reef docs shots

Light-theme product shots used by the landing page and docs (`website/public/reef/`).
They are posed HTML of Reef's light palette, captured at 2× so they stay sharp
on the dark site.

```sh
# system Chrome + ffmpeg (gif only)
bun website/scripts/shots/capture.mjs
bun website/scripts/shots/capture.mjs time-travel   # one scene
```

Open `reef.html?shot=board` in a browser to preview a scene.
